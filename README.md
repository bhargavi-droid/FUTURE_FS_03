Aurora Coffee Lounge

Aurora Coffee Lounge is a modern and responsive café website developed using HTML, CSS, and JavaScript. This project was created as part of a Full Stack Web Development Internship task to design a professional website for a real local business.

The website provides an elegant digital platform for a café business with visually appealing sections such as hero banner, about section, signature menu, services, gallery, customer testimonials, reservation form, and contact details. The design focuses on modern UI/UX principles, smooth navigation, responsive layouts, and premium visual aesthetics.

Project Purpose

The purpose of this project is to help local businesses improve their online presence through a professional and user-friendly website experience. The website can help attract customers, showcase products and services, and improve customer engagement digitally.

How to Run the Project
Download or clone the repository
Open the project folder in Visual Studio Code
Open index.html in a browser
